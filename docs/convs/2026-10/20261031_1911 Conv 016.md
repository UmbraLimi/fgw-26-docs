## Learnings
- **Workers runtime / `Date` at module scope / Never read time in a module top-level const.** On the
  Cloudflare Workers runtime, `new Date()` / `Date.now()` evaluated at a module's global scope returns
  epoch 0 (year 1970); a value derived from it and exported as a const is frozen wrong for every consumer.
  Compute time inside a function/handler that runs at render/request time. Now enforced by an eslint rule.
- **Green ≠ proven; the running product is the only truth.** `npm run verify` was green through two prior
  convs while the live site served "-12 years" — the Node test clock masked a Workers-only defect. The
  CLAUDE.md "verify in the running product" rule is what surfaced it (a `curl` of live staging).
- **Prefer deferral over a value when a platform freezes global scope.** A function that computes on call
  dodges a whole class of "evaluated too early" platform quirks; a const that captures a runtime value at
  import time is the trap.

## Learnings
- **Contrast is measured, not eyeballed.** Deepening the paper to make the warmth read dropped
  ember-on-paper text below WCAG AA (ember `#b45309` = 4.14:1, fails small text). A quick contrast script
  caught it *before* shipping, forcing the ember-as-text → `--accent-strong` split. The "verify, don't
  assume" rule paid off concretely.
- **The Chrome extension can't open `file://`.** Rendering local scratch HTML / the dev build for
  screenshots needs an `http://localhost` server (`python3 -m http.server` for static; `astro dev` for
  the app). Also: `astro dev` has a `predev` Node-floor check — scripts must `nvm use` (Node 24) first.
- **Commit at will; don't surface `/r-commit` as a question.** Operator: there's no downside to committing
  except when a related batch is mid-flight and incomplete — then elect to hold. Reinforces the existing
  "standing right" rule; I had been over-offering it as a choice.
- **Pattern — show, don't describe, for design forks.** Building each option against the running product
  and screenshotting it (into `.scratch/`) converged far faster than prose proposals; the operator
  reacted to pixels and redirected in one line each time.

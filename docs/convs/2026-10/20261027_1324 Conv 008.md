## Learnings
- **Astro Cloudflare adapter selects the env at build, not deploy.** The adapter flattens the wrangler env
  into `dist/client/wrangler.json` from `CLOUDFLARE_ENV`; `wrangler deploy --env` is too late. Vite `--mode`
  and `CLOUDFLARE_ENV` are independent — mode only loads the `.env` file; the plugin keys off the variable
  inside it. Verify the resolved artifact, not the inputs. (→ guard pattern, `DEC-008-1`.)
- **wrangler's local dev reads `.env*` as runtime secrets when `.dev.vars` is absent**
  (`CLOUDFLARE_LOAD_DEV_VARS_FROM_DOT_ENV` defaults true) — the reason the two families must stay separate.

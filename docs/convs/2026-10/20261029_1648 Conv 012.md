## Learnings
- **Astro v6 / `@astrojs/cloudflare` v14 removed `Astro.locals.runtime.env`** — read env via
  `import { env } from "cloudflare:workers"`. Caught only by exercising the endpoint in the real runtime;
  the build + unit tests were green while the first version was wrong.
- **Astro view transitions reset `<html>` attributes on swap**, so a persisted theme drops on client-side
  nav unless re-applied on `astro:after-swap`. It hid during testing because the `navigate` tool does full
  page loads — **verify UX through the real interaction path (in-page nav), not just full loads.**
- **Guards that read build artifacts drift silently across adapter upgrades.** The v14 config-path move
  (`dist/client/` → `dist/server/`) broke the deploy-name guard; it only "passed" on stale leftover files.
- **Resend mandates no env var names beyond `RESEND_API_KEY`;** `from`/`to`/`reply_to` are request fields.
  `EMAIL_FROM`/`EMAIL_TO`/`EMAIL_DOMAIN` are app conventions, not Resend requirements.

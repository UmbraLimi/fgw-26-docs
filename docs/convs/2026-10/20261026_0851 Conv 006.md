## Learnings
- **A conservative default can quietly cost two LTS lines.** I pinned Node to the minimal bump
  (22.23.4) that cleared Astro's floor; the operator rightly flagged that "works" isn't "current", and
  since nothing capped the upper bound, active LTS was the better start-of-project call. Check the
  ceiling, not just the floor.
- **A Node-major move is also an npm-major move.** Node 24 bundles npm 11, whose install-script
  blocking changed install semantics. Verify a *clean* reinstall (`rm -rf node_modules`), not just an
  incremental one, when changing the runtime.
- **"Verify in the running product" earned its keep** (`DEC-000-7`): the contrast review, the two
  styleguide nits, and the `undici`-override/miniflare compatibility all needed the live server — none
  would have shown up in green gates alone.

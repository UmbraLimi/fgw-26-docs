## Learnings
- **Context: `git add a b c` where one path doesn't exist. Learning: `git add` aborts atomically — a single
  bad pathspec stages *none* of the listed paths. Pattern: re-check `git status` after a multi-path add that
  errors; a separately-staged `git rm` deletion can make the commit still succeed while holding only that deletion.**
- **Context: env detection in an Astro/Vite build. Learning: `import.meta.env.PROD` is `true` for both the
  staging and production builds (it tracks `NODE_ENV`, which `vite build` forces to `production` regardless
  of `--mode`); only `import.meta.env.MODE` distinguishes them. Pattern: gate per-environment behavior on MODE.**

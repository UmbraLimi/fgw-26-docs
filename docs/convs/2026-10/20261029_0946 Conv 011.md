## Learnings
- **Context:** `npm run verify` died in `astro check` on a fresh shell. **Learning:** the cause was the
  nvm `default` alias (`~/.nvm/alias/default`), not the project — a wrong default silently activates a
  below-floor Node on every new shell. **Pattern:** when a tool reports the wrong runtime version, check
  the version manager's *default alias*, not just `.nvmrc`/PATH.
- **Context:** the callouts needed an on-brand accent treatment. **Pattern:** the existing
  `.prose blockquote` ember left-rule was reusable — preferred over new CSS, keeping the Conv-010 visual
  system intact.

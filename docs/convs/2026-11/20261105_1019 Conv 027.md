## Learnings
- **Astro routing / tests.** Any `*.test.ts` under `src/pages` is treated as a route and prerendered at
  build (it broke the build here). Keep endpoint tests out of the routable tree — an underscore prefix
  (`_contact.test.ts`) is the idiomatic Astro exclusion while vitest still globs it.
- **Verify a field against its consumers, not its name.** `proof`/`outcome`/`problem` on Work cases *look*
  like SEO fields but are rendered by nothing; only `summary` ships. A mid-conv hopper note asserted the
  opposite from memory and had to be corrected — the grep for `data.<field>` was the fix.
- **Pattern — pricing as a qualifier.** For a judgment/steering value proposition, a project-scale floor
  qualifies buyers without commoditising; an hourly rate invites the exact race-to-the-bottom the
  positioning thesis argues against. Keep it on the self-qualification funnel, not a `/pricing` page.

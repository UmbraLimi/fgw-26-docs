## Learnings
- **Preview-then-pick worked for styling.** Applying 2–3 candidate treatments client-side in the browser
  and screenshotting each let the operator choose by eye ("I cannot tell which changes to make") where an
  abstract description would have stalled — then the real CSS was verified in the running product.
- **"Lift the heading, don't indent the items"** is the FAQ/accordion convention (from web research this
  conv) — worth remembering for the deferred site-wide section-heading decision.

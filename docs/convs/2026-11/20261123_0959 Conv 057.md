## Progress
This conv executed the Phase-2 guides-only launch that `DEC-056-3` decided. The crux was that one flag
(`CONTENT_HOME_LIVE`) gated both `/guides/` and `/writing/`; flipping it would have exposed an empty
`/writing/`. So the flag was split: `CONTENT_HOME_LIVE=true` lights the guides, a new `WRITING_LIVE=false`
keeps the dated stream dark (its hub stream, `/writing/` pages' noindex + sitemap inclusion, and the footer
link). A second, non-obvious blocker surfaced only when inspecting the build output: the three guides were
still `draft:true`, and `getStaticPaths` is draft-filtered, so prod generated the hub but none of the guide
pages — the live hub would have linked to 404s. Flipping them `draft:false` fixed it. `npm run verify`
passed; the split was confirmed in the built output **and** in the live product (200s, noindex on `/writing/`
only, sitemap carries the 4 guide URLs not `/writing/`, `/blog` 301→`/guides/`). The code + bookkeeping were
committed mid-conv via `/r-commit` (docs `aff5833`, code `c922ee3`) so prod matches a commit.

## Learnings
- **"Final/graduated" ≠ `draft:false`.** A guide can be operator-declared final and graduated to a dossier
  while its content-collection `draft` flag is still `true`; a prod build filters drafts out via
  `getStaticPaths`, so going live needs the draft flip **in addition to** the live-flag. The handoff's
  6-step launch sequence omitted this step; it was caught only by inspecting the actual build output, not by
  trusting the flag flip. Verify a launch in the built/running product, not just that the switch moved.
- **Split a single dark-flag when a subset must go live independently.** `CONTENT_HOME_LIVE` bundled guides
  + writing; a guides-only launch needed them decoupled. One boolean (`WRITING_LIVE`) keeps the deferred
  half re-enableable without touching the live half.

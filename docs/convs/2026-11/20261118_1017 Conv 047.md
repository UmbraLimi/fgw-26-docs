## Learnings
- **Dev image-cache trap.** Replacing a content image in place during `astro dev` leaves Chrome serving
  the old bytes on the unchanged `/_image` URL; a lazy below-fold image isn't fixed by Cmd+Shift+R. Bust by
  renaming the file or "Empty Cache and Hard Reload". Prod unaffected (content-hashed). (In COLOPHON.md.)
- **A guard can't verify intent, only a proxy.** The routing guard couldn't confirm a route reached a
  durable file — so it shifted to a nudge the operator verifies, not a gate that pretends to check.

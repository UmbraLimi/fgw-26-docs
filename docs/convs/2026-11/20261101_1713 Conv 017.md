## Learnings
- **CSS modifier specificity ties lose on source order.** A single-class `.band-tight` tied the base
  `.band` and lost because `.band` is defined later in the stylesheet; the white sections worked only by
  luck of order. Compound the selector (`.band.band-tight`) to win regardless. Caught live via the bridge
  (bands measured 112px despite the modifier).
- **`<details>` fragment auto-open needs an inner target.** Navigating to a fragment that *is* the
  `<details>` only scrolls; the ancestor-reveal that opens it fires only when the fragment targets an
  element *inside* the details. Move the `id` onto an inner element. Verified Chrome 156.
- **"Didn't work" was stale browser CSS, not wrong code.** The served output was correct throughout; the
  check is a hard refresh or a live measurement, not re-reading the source (`DEC-000-7`).

  principle, the dossier format — not the one guide's copy. Each process learning folds into the pipeline
  docs so the next piece is faster; piece-specific calls go to the dossier. The split (process → pipeline
  docs; piece → dossier) is the discipline that turns a slow guide into leverage.

  the lede paragraph (and the hub card); only `snippet` is invisible meta. So the lede is caught in the
  rendered read, while the snippet's only review gate is GUIDE-REVIEW step 13 — the reason the snippet needs
  an explicit after-prose reconsideration.

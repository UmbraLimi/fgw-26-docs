## Learnings
- **Astro ClientRouter + forms.** With view transitions on, a `<form>` POST is intercepted as a
  client-side nav unless the JS handler `preventDefault`s first — and a bundled module script isn't
  reliably attached per-nav. Pattern: `is:inline` + re-bind on `astro:page-load`, with `data-astro-reload`
  as the native-submit backstop.
- **@astrojs/cloudflare named envs.** The adapter flattens top-level + env config at build and does NOT
  override `routes` per env, so a named-env deploy silently inherits prod routes. Pattern: set `routes: []`
  in every non-prod env, and guard it (`assert-worker.mjs`).
- **`display:contents`.** Percentage heights don't resolve through a `display:contents` element — a child's
  `height:100%` falls back to intrinsic sizing. Pattern: absolute-fill for fixed-aspect boxes.

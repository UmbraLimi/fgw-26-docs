> The Problem section

> The translation project set out to translate long, terminology-dense text and keep it faithful, not only grammatically, but in its specialized vocabulary. Translation services like DeepL work very well with general speech but struggle with preserving meaning when a pre-specified, pre-translated glossary must be adhered to. This is particularly evident in phrases like "X of the Y" when the context in different sentences is slightly different (e.g. used a a plural). The various forms of words (plurals, formality, gender) became inconsistently translated. For a work defined by the precision of its terminology, that inconsistency is a big problem. The system was architected to learn from human review, create rules and on subsequent runs of the pipeline apply the updated rules. This makes translations repeatable. In other words, we were out to minimize the size of the black box that is AI translation for complex texts.

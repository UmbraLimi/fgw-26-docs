## Learnings
- **GSC is stale right after a cutover.** The new site is ~1 day old to Google; most "errors" are old-site
  data not yet re-crawled. "Alternate page with proper canonical tag" is a benign/informational status.
  Investigate-and-assess, report, let re-crawl settle it — don't chase as new-site bugs. (Operator: "I was
  too quick to deal with GSC errors.")
- **Production deploy needs auto-mode off.** `npm run deploy` (prod `wrangler deploy`) is blocked by the
  auto-mode classifier ("Production Deploy"). Report the block and wait; don't work around.
- **X limits (verified live):** bio **160**, display name 50, location 30; the "Expanded Bio" longer-bio
  feature was removed ~March 2026, so 160 is the ceiling for free and Premium.

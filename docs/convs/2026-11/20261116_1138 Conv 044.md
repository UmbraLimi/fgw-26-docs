## Learnings
- **GSC indexing read.** The all-known-pages "Indexed" count conflates real pages with old-URL 301 ghosts and
  stale pre-submission crawls. Filter to **All submitted pages** and apply a crawl-date floor (first sitemap
  submission) to get the true indexed/crawled picture; don't relay the mixed view.
- **Request-indexing gotcha.** Its live fetch can falsely reject a healthy page with "Page fetch — Failed:
  Server connection error" (verified `/method/` served HTTP 200 at the same instant). Re-run the live test
  (↻) until green, then request; likely transient rate-limiting from rapid back-to-back probes.
- **GSC property access.** The `frasergorrie.com` property is a **domain property** under the
  `fraser@frasergorrie.com` Google account; navigating to the URL-prefix `https://frasergorrie.com/` form (or
  a bare `/search-console` URL) bounces to the welcome/no-access screen. Select the domain property from the
  picker.

## Learnings
- **Astro `is:inline` placement.** A page-level `<script is:inline>` placed *after* `</SiteLayout>` lands
  outside `<html>` and never runs; it must sit inside the layout's slotted content (as RecordMethod's does).
  Cost a first failed lightbox attempt, caught by verifying in the browser.
- **SVG-as-image sized to the box ratio.** Generating the map SVG at a 2:3 canvas (not its natural ratio)
  lets `object-fit: cover` fill the mockup box with no letterbox — simpler than a per-case `object-fit` flag.
- **`package.json` is identifying.** It carries `name`, org, GitHub URL, and D1/R2 resource names — extract
  only the generic dependency names for a de-identified "BUILT WITH"; never the project/resource names.
- **Pattern:** for proprietary client work, a *representative* (not accurate) diagram, captioned as such and
  with the honesty label baked into the asset, satisfies the visual while staying NDA-safe and on-thesis.

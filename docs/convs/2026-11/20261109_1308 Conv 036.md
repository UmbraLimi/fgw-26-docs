## Learnings
- **LinkedIn image media has no click-through** — tapping it only opens the image. A testimonial card
  needs a companion **link** item for the funnel; the operator also moved the pair into the **Experience**
  entry's media (permanent) because Featured "reads as ephemeral".
- **Skills reorder ≠ pinned "Top skills"** — the displayed Top-3 are set in the About editor, not by
  reordering the Skills list.
- **`file_upload` beats the native picker** — the cover-photo uploader opens an OS file dialog the bridge
  can't drive, but Featured/Experience media file `<input>`s are settable directly via `file_upload` (located with `find`). Render brand images from an HTML+SVG source via headless Chrome (`--screenshot`, 2× scale).
- **The browser `type` action intermittently drops characters** in some LinkedIn fields — verify URLs and
  copy (zoom) before submitting.

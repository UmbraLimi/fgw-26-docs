## Learnings
- **Browser / responsive checks.** The `claude-in-chrome` `resize_window` did not shrink the page's CSS
  viewport (it stayed at the desktop breakpoint), so a narrow-window screenshot won't verify mobile
  layout. Verify mobile stacking from DOM child order + the `@media` fallback via a JS inspection instead
  — deterministic and viewport-independent.
- **Form-validation testing.** A programmatic `element.value = …` does not mark the control dirty, so
  `validity.tooShort` (and other edit-gated constraints) stay false. Exercising a `minlength` path needs
  real keystrokes (the computer `type` action), not a scripted value set — this turned a false "no error"
  into a confirmed-correct result.

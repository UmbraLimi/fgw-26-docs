## Learnings
- **Context:** the provisional `'/blog': '/'` redirect in `astro.config.mjs`. **Learning:** an Astro
  `redirects` entry **shadows a real page route of the same path entirely** — `/blog/` emitted no page at
  all (prod *and* `astro dev`) while it stood, not just a double-hop. **Pattern:** when a page won't render,
  check `redirects` before the page itself.
- **Context:** `.eyebrow-rule` is `display: inline-flex`. **Learning:** placing an inline element (a
  back-link) immediately before it puts both on the same line — they collided. **Pattern:** a block break
  needs a block element; `mt-*` on an inline-flex element doesn't force a new line.
- **Context:** previewing a dark/unlaunched feature. **Pattern:** gate it on `FLAG || import.meta.env.DEV`
  so it's committed, stays dark in prod/staging, and previews in dev — cleaner than uncommitted working-tree
  edits reverted each conv (`DEC-039-4`).
- **Context:** Chrome automation `resize_window`. **Learning:** on this machine the window clamps at
  ~1006px viewport; couldn't force a true 768px capture. **Pattern:** verify the tight breakpoint by
  reasoning from the widest in-band capture + the element gap, or note the gap it leaves.

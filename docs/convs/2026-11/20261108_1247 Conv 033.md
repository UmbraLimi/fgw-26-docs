## Learnings
- **Cloudflare Bot Preference Sync.** The AI-crawler access policies (Search/Training/Agents) are enforced
  at the edge; "Bot Preference Sync" is a *separate* toggle that additionally prepends them into robots.txt.
  Disable the sync to let the repo own robots.txt while keeping edge enforcement — the managed block can't
  be edited line-by-line.
- **ClientRouter + hash anchors + sticky header.** `scroll-padding-top` on `html` is honoured by Astro
  ClientRouter's hash navigation (not only native load), and is the clean fix for an anchor target landing
  under a sticky header.
- **Deploy ≠ commit, and ≠ live.** `npm run deploy` builds from the working tree (so it can ship uncommitted
  edits), while `/r-commit` and `/r-end` only record/push source — committed work stays off the live site
  until a deploy runs. Easy to conflate when a deploy is blocked.

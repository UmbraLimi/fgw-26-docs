## Learnings
- **"Verified" must name what was checked — responsive work needs a check per breakpoint regime, not
  just the extremes.** The first header-title pass was reported verified from wide + mobile reasoning,
  but the untested mid-band (full nav + 768px container cap) was the one broken case the operator then
  found.
- **Browser-tool viewport sizing is unreliable here; force-show + measurement is a workable fallback.**
  `resize_window` repeatedly refused to drop below ~1024px. Forcing the element visible (`display:block`
  + `.title-shown`) and measuring geometry verified rendering, row height, and anchor clearance
  independent of the viewport width.

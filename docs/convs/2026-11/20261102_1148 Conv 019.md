## Learnings
- **Existing data before new flags.** The `client` field (`DEC-004-2`) already encoded client-vs-personal but
  was never surfaced; the Client badge reused it rather than adding a new flag. Check what the data already
  carries before inventing a field.
- **Astro dev + schema edits.** Removing a field from `content.config.ts` did not hot-reload cleanly — the
  running dev server served an error page until restarted. Restart `astro dev` after content-config/schema edits.

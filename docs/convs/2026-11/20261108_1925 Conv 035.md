## Learnings
- **Verify against the real target, not a fabricated proxy.** The "307 redirects" alarm came from
  invented `.html` URLs that were never configured; the sitemap "1 URL" from `grep -c` on single-line
  XML. Both wrong, both caught by re-checking the actual artefact. Re-verify before surfacing a finding.
- **A second instance is the signal to build the shared mechanism.** One periodic task didn't justify
  `/r-start` machinery; the second (same conv) did — pre-registering that trigger made the call clean and
  avoided both premature framework-building and perpetual hand-maintained markers.
- **Inherited third-party setup is a cleanup surface.** "Aligning Google" was really fixing the old
  site's GSC config — a wrong sitemap URL had silently starved indexing. Audit inherited external state;
  don't assume it matches the new site.

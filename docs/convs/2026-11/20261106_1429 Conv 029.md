## Learnings
- **Staging routes 307-redirect `/<page>` → `/<page>/` (trailing slash).** Verification `curl`s without
  `-L` return 0 bytes and look like a missing change — use `curl -sL`. Home (`/`) is already canonical, so it
  masked the problem at first.
- **Client content sign-off vs house-style edits.** The operator's framing: a spelling/style standardisation
  is not a "change" to signed-off content because it alters no claim, name, or fact — worth remembering when
  a future edit touches approved material (substance is the test, not the diff).
